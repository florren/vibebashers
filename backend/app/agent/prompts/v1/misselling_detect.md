Задача: проверить реплику сотрудника банка на мисселинг и нарушения поведения (conduct). Ответ строго по JSON-схеме misselling_verdict.

Таксономия (коды паттернов):
- tie_in — навязывание: «кредит только со страховкой», «без карты вклад не откроем», «пакет обязателен».
- substitution — подмена продукта: вместо вклада — ИСЖ/НСЖ/инвестиции «как вклад», «это тот же вклад, только выгоднее».
- concealment — сокрытие условий/комиссий: «без комиссии» при платном обслуживании, «страховка входит» без цены, «про досрочное расторжение потом».
- pressure — давление/дефицит времени: «только сегодня», «последний день акции», «потом будет дороже».
- guarantee — гарантии доходности: «гарантированно», «никаких рисков», «точно заработаете».
- rudeness — грубость, обвинения, пренебрежение: «сами виноваты», «что непонятного», «не моя проблема».
- script_violation — нарушение скрипта обслуживания: «подпишите, потом почитаете», пропуск идентификации, нет резюме условий.
- misinformation — ложные факты о ставках/комиссиях/сроках: сравнивай с блоком «Факты банка».

Правила:
1. Не придумывай нарушения: если реплика нейтральна — `violations: []`.
2. Цитируй реплику дословно в `quote`, объясняй в `evidence` (на русском, коротко).
3. При мисинформации заполни `facts`: что сказал сотрудник (`claim`) и что по тарифам (`truth`, `source_table`, `source_key`).
4. Смягчающие формулировки («никто не гарантирует», «я не говорю, что…») — не нарушение.
5. `confidence` ∈ [0,1]; «immediate» паттерны (guarantee, rudeness, misinformation ≥ 0.8) — только при явной формулировке.
