# Пятиминутный показ CX Pulse Control

Раскадровка для ведущего: **~5 минут**, один экран 1920×1080. Хребет — живые контуры BRD/ДТЗ (сценарии **8 → 9 → 10**) и один заход на `/engine`. Рабочее место `/` — короткие взгляды на **Карту**, **HITL** и **Дашборд**, если уложились в таймер.

Экраны и маршруты существуют в приложении: `/`, `/feed`, `/compliance`, `/manager`, `/engine`, `/setup`. Меню демонстратора (Ctrl+Shift+R), бейдж режима в футере, живой микрофон на комплаенсе и QR Telegram-бота **в этот показ не входят**.

## План Б: LLM и офлайн (replay → mock)

По правилам подстраховки ответы модели идут из кассет **replay**, затем **mock**; на `/feed` у публичного ответа виден источник `llm_source` (`live` | `replay` | `mock`).

| Ситуация | Действие |
|---|---|
| **До показа**, сеть или ключи ненадёжны | `./install.sh --offline` — пишет `LLM_CHAIN=replay,mock` в `.env` и поднимает стенд через `compose up` (см. таблицу флагов в README, §1.4). |
| **В ходе показа** модель недоступна (таймаут, 429) | Записать `LLM_CHAIN=replay,mock` в `.env`, затем **пересоздать** backend с новым окружением: `docker compose up -d backend` (`env_file: .env` подхватывается при создании контейнера; `docker compose restart` **не** перечитывает `.env`). Либо мастер **http://localhost:8000/setup** — изменить цепочку LLM и **применить** (запись в `.env` + `apply_runtime` в процессе, без пересоздания контейнера). Нативный `make dev` — тот же мастер или `PUT /api/settings/env` с `apply: true`. |
| **Проверка режима** на сценарии 8 | `/feed` → под ответом агента смотреть метку `llm_source`; для офлайн-показа ожидаются `replay` или `mock`, не «тишина» без ответа. |

Контуры `/feed` и комплаенс по транскриптам **не зависят от паузы симулятора** — эмуляцию на `/` можно не трогать или держать на «Стоп».

## За 10 минут до выхода

- `curl -s localhost:8000/api/health` → `"db": true`.
- Открыть вкладки: `/feed`, `/manager`, `/compliance`, `/engine`, `/` (рабочее место).
- При сомнении в LLM — сразу план Б (`./install.sh --offline` до выхода или смена `LLM_CHAIN` + `docker compose up -d backend` / мастер `/setup`).
- Уведомления ОС выключить, масштаб браузера ~110 %.

## Раскадровка (~5:00)

| Время | Экран | Действие | Что сказать (тезис) |
|---|---|---|---|
| **0:00–1:30** | `/feed` | **Сценарий 8** — комиссия QR и публичный ответ. **Основной путь показа (возврат по правилу):** `make scenario ID=8` или `ID=qr_fee_public_review`. Сценарий через `inject_operation` создаёт операцию `qr_sbp` с `fee_amount` и кодом `PROC-QR-FEE-CHARGED` — без этого **RULE-QR-FEE-001** (`operation.method=qr_sbp`, `fee_amount>0`) не срабатывает. Пост и сигнал появляются на `/feed`. | «Клиент пишет на внешней площадке; агент не ждёт оператора: правило подтверждает ошибочную комиссию, возврат в Mock-АБС и публичный ответ без ПДн.» |
| | `/feed` | После **только** `make scenario ID=8`: дождаться ответа под постом (~2–5 с), виджет **«АБС (эмуляция)»** — зелёная проводка возврата; при наличии — полосу «Возвращено» / «Авто / HITL». Отметить `llm_source` при офлайн-режиме. **Запасной путь UI** (если движок сценариев недоступен): «Опубликовать отзыв» (`POST /api/public/reviews`) — только пост и разбор агента; операцию в АБС он **не** создаёт. Можно показать ленту и ответ, но **не** обещать автоматический возврат — для сюжета с RULE-QR-FEE-001 нужен `make scenario ID=8`. Последние 4 цифры в форме — подсказка для сопоставления клиента из сида, не фиксированные «4512» из yaml. | «Деньги — только по правилу и инструменту возврата, не «по мнению модели».» |
| **1:30–2:45** | терминал → `/manager` | **Сценарий 9** — мисселлинг в отделении: `make scenario ID=9` (файл `scenario09_isj.json`, ВСП **0042**). **Запасной путь:** `/compliance` → импорт того же файла из корпуса (кнопка «Импорт корпуса» / загрузка, как на экране). | «Аудиомониторинг отделения: не прослушивание архива, а разбор транскрипта — подмена, сокрытие, навязывание.» |
| | `/manager` | Алерт руководителю (порог срабатываний). «Разобрать» / перейти к транскрипту. | «Руководитель видит карточку с цитатами, а не ссылку на запись.» |
| **2:45–3:45** | терминал → `/manager` → `/compliance` | **Сценарий 10** — грубость и неверная ставка: `make scenario ID=10` (`scenario10_retail.txt`). **Запасной путь:** импорт файла на `/compliance`. | «Красные фразы и неверный факт: факт-чек по тарифам в БД — сказано 14 %, по продукту 9,5 %.» |
| | `/compliance` | Открыть отчёт по транскрипту: находки `rudeness`, `misinformation`, пропущенные шаги скрипта. | «Один проход правил + модель на готовом тексте — страховка живого STT.» |
| **3:45–4:45** | `/engine` | После сценария 8 (или последнего прогона агента): вкладка последнего **run** → **Шаги** (классификация / решение / инструменты) или **Граф** / **Цепочка решений**. | «Каждое решение воспроизводимо: промпт, ответ, инструменты, правила — для аудита и обучения.» |
| **4:45–5:00** *(если есть секунды)* | `/` | Вкладка **«Карта»** — тепло или зоны; **«Требует решения» (HITL)** — одна карточка в очереди; **«Дашборд»** — KPI, блок экономики (**потенциальные** и **предотвращённые** потери по dCLTV). | «Где болит географически, где человек обязателен, сколько стоит инцидент по формуле банка.» |

## Ручной чек-лист (приёмка T-151)

Отметьте после репетиции с секундомером; пункты про вторую машину и полный CI — вне этой правки.

- [ ] План Б описан и проверен: `--offline` до показа или смена `LLM_CHAIN` + `docker compose up -d backend` / мастер `/setup` (не `compose restart`); на `/feed` виден `llm_source`.
- [ ] Сценарий **8** через **`make scenario ID=8`**: ответ под постом + виджет АБС с возвратом; правило **RULE-QR-FEE-001** (операция `qr_sbp` с комиссией из inject). Ручная публикация отзыва — только без обещания зелёной проводки.
- [ ] Сценарий **9**: алерт на `/manager`; при сбое `make scenario` — импорт на `/compliance`.
- [ ] Сценарий **10**: «немедленный» алерт и отчёт на `/compliance` с факт-чеком ставки.
- [ ] `/engine`: показан хотя бы один прогон с шагами или цепочкой решений.
- [ ] *(опционально)* `/`: Карта, HITL или Дашборд с экономикой — если уложились в ~5 мин.
- [ ] Показ **не** опирается на меню демонстратора, QR бота и живой микрофон как обязательные шаги.
- [ ] Хронометраж ~5 мин на вашем железе (отдельная репетиция).
- [ ] Установка на второй машине только по README (отдельная проверка участником).
