# ADR-0005 — Симуляционное время отдельно от реального

| Поле | Значение |
|---|---|
| Статус | принят |
| Дата | 20.10.2026 (уточнён 27.10.2026: рабочий день 09–18) |
| Решение принял | техлид (Денис); подготовил архитектор |
| Связанные разделы | AGENTS.md правила 6, 7, 15; ТЗ 4.1, 4.7, 8, 26.2 |

## Контекст
Банк эмулируется с ускорением; SLA, терпение клиентов и отчёты команд должны считаться в «банковском» времени, а живые контуры демо (`/feed`, `/compliance`, «Надиктовать») — реагировать за реальные секунды.

## Решение
`SimClock` и поля `*_sim` для всего, что порождает симулятор; `*_at` — реальное время. Рабочий день симулятора — пн–пт 09:00–18:00 (решение 20.7 № 71; формулировка ТЗ 4.1 приведена к коду). Живые контуры не зависят от сим-времени (правило 15, `sim_runs.kind = live`). Циркадная тема интерфейса на защите идёт по симуляционному времени (20.7 № 67).

## Последствия
Все расчёты SLA/терпения — в рабочих сим-часах; тесты детерминированы по сиду. Изменение рабочего дня — только через `sim_state` и новый ADR.
