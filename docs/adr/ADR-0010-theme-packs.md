# ADR-0010 — Семантические токены и пакеты тем brand и ops

| Поле | Значение |
|---|---|
| Статус | принят |
| Дата | 27.10.2026 |
| Решение принял | техлид (Денис); подготовил архитектор |
| Связанные разделы | ТЗ 26.1–26.4, 12.1, 20.7 № 44, № 67, № 68; карточки T-251–T-254 |

## Контекст
Три несовместимые палитры: индиго из ЕТЗ, «ситуационный центр» прототипа 2.4 и зелёный бренд из решения заказчика № 12. Экраны должны оставаться «тихими», контраст ≥ 4,5 : 1, без внешних библиотек тем.

## Решение
Все цвета и размеры — через семантические токены (`--surface-*`, `--ink`, `--brand`, `--ok/--warn/--danger`, `--signal-*`, `--zone-*`, `--trace-*`). Значения хранят пакеты тем: `brand` — основной (значения ТЗ 12.1), `ops` — **запасной** пакет для тёмного зала/проектора и режима «Ситуационный центр» (решение техлида 27.10.2026, 20.7 № 68). В шапке — селектор темы (пакет × режим `light/dark/auto/circadian`); выбор хранится в `settings` и `localStorage`. Индиго основным не становится; цвета данных (маркеры ВСП, уровни) от пакета не зависят.

## Последствия
Существующие экраны не меняют вид в `brand`. Контраст проверяется юнит-тестом по токенам в каждом сочетании пакет × режим × фаза. Новая палитра = новый пакет, а не правка компонентов.

## Уточнение реализации T-251 (28.10.2026)

Пакет ops использует уже включённые в проект sRGB-токены. Исходные стили прототипа 2.4 в репозитории отсутствуют; пользователь уточнил, что стиль был сгенерирован другой нейросетью. Точное совпадение с этим исходником не заявляется. Контраст проверяется по фактическим CSS-декларациям (не по копии палитры в тесте). Основной бренд #21A038 сохраняется; для небольшого текста/кнопок применены отдельные контрастные semantic foreground/strong tokens, декоративные zone/signal colours от пакета не зависят.

Настройки `ui.theme_pack/mode/density` синхронизируются PATCH только выбранных ключей, с очередью и сохранением неотправленных изменений в localStorage. Ошибка видна пользователю; следующий mount повторяет отправку. Изменения пользователя во время GET приоритетнее устаревшего ответа. До загрузки приложения inline bootstrap применяет сохранённый pack/mode/density/phase. Auto следит за ОС; базовый circadian использует шесть фиксированных интервалов сим-времени в Europe/Moscow и последний сохранённый phase до первого tick. Солнечные расчёты, ручной/real источник, интерполяция и ночной дайджест остаются T-252.


При проверке PR #72 уточнён приоритет локального выбора: значения, изменённые после запуска начального GET, сохраняют приоритет и после подтверждения PATCH. Очередь неотправленных изменений и журнал выбора за время GET разделены, чтобы запоздалый ответ не возвращал старую тему. Для обычного брендового текста используется отдельный `--brand-foreground`; декоративный `--brand` остаётся исходным цветом. Контраст ссылок проверяется также по фактическим стилям браузера на экране следа.
