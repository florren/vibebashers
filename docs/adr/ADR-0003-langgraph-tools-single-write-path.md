# ADR-0003 — LangGraph и инструменты как единственная точка записи агента

| Поле | Значение |
|---|---|
| Статус | принят |
| Дата | 20.10.2026 (зафиксирован 27.10.2026) |
| Решение принял | техлид (Денис); подготовил архитектор |
| Связанные разделы | AGENTS.md правила 2, 3, 14, 18; ТЗ 9 |

## Контекст
Агент должен быть объясним («Под капотом»), воспроизводим и безопасен: модель не может писать в БД или двигать деньги «по своему мнению».

## Решение
Граф LangGraph с чекпоинтером в PostgreSQL; узлы — чистые функции над `AgentState`; все записи — через инструменты из `contracts/events/agent/tool_call.schema.json`, каждый вызов логируется в `agent_steps.tool_calls`. Структурированные выходы валидируются Pydantic-моделями из контрактов, один retry, затем fallback на mock с пометкой. Деньги — только `refund_fee` при `rule_evaluations.result = matched` (правило 14).

## Последствия
Любая новая способность агента = новый инструмент + схема + тест. Трассировка полна по построению, что делает возможными «Путь обращения» и «След» (ADR-0011).
