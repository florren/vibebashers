## Контекст
Нужны шина событий симулятора, фоновые задачи и обновления WebSocket ≤ 1 с; при этом — один процесс и минимум инфраструктуры.

## Решение
Шина событий — таблица `sim_events` + `pg_notify`; фоновые задачи — `asyncio` в процессе `uvicorn`; состояние для возобновления (RNG, чекпоинты LangGraph, followups) — в БД. Redis, Celery, Kafka не используются.

## Последствия
Горизонтальное масштабирование не требуется и не поддерживается; при росте нагрузки — отдельный ADR. Все подписчики обязаны переживать переподключение к PostgreSQL.
