# ADR-0006 — Модель поведения клиентов и LLM-двойники

| Поле | Значение |
|---|---|
| Статус | принят |
| Дата | 20.10.2026 (зафиксирован 27.10.2026) |
| Решение принял | техлид (Денис); подготовил архитектор |
| Связанные разделы | AGENTS.md §6.1; ТЗ 4.5, 14.5 |

## Контекст
Экономика удержания и метрики должны считаться по разыгранным исходам, а не по константам; при этом вызовы LLM для 5 000 клиентов недопустимы по стоимости и времени.

## Решение
Параметрическая модель психотипов и состояний (`data/psychotypes.yaml`, `app/sim/behavior`) для всех клиентов; LLM-двойники — только для «подсвеченных» (сценарии, HITL, vip/ultra_vip, лимит в сутки); двойник видит лишь то, что видел клиент. Уход → `churn_events` + инцидент `account_closure`.

## Последствия
Схема психотипов и параметры меняются только в данных и через ADR. Коэффициенты удержания калибруются по `v_retention_by_outcome`.
