# ADR-0004 — Провайдеры LLM за единым интерфейсом и цепочка failover

| Поле | Значение |
|---|---|
| Статус | принят |
| Дата | 20.10.2026 (зафиксирован 27.10.2026) |
| Решение принял | техлид (Денис); подготовил архитектор |
| Связанные разделы | AGENTS.md §6.3, §6.9; ТЗ 5 |

## Контекст
Демо должно работать с GigaChat, OpenRouter-моделями и без сети; квоты бесплатных моделей ограничены.

## Решение
Единый интерфейс `app/llm/provider.py` (`complete_structured`, `stream`); реализации `gigachat`, `openai_compat`, `replay`, `mock`; цепочка `LLM_CHAIN` с таймаутами по контексту (`failover.py`); пул ключей и rate limiter per profile. Офлайн — кассеты `replay` реальных моделей, `mock` — последний резерв; источник каждого шага (`live|replay|mock`) виден в UI (правило 16).

## Последствия
Любая ошибка провайдера не останавливает симуляцию. Смена промпта требует перезаписи кассет (`stale`).
