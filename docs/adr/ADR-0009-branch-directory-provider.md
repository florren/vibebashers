# ADR-0009 — Справочник ВСП через BranchDirectoryProvider без внешних вызовов

| Поле | Значение |
|---|---|
| Статус | принят |
| Дата | 27.10.2026 |
| Решение принял | техлид (Денис); подготовил архитектор |
| Связанные разделы | ТЗ 25.4, 20.7 № 35, № 53; AGENTS.md правило 8 |

## Контекст
ЕТЗ описывает загрузку реестра отделений из внешнего сервиса (SOAP, cron) с ОКАТО; правило 8 запрещает внешние сетевые вызовы, а реальные адреса отделений — брендированные данные.

## Решение
Интерфейс `BranchDirectoryProvider` с двумя реализациями: `synthetic` (по умолчанию — детерминированная сеть ≈ 240 ВСП по субъектам РФ, типы, статусы, даты, ≈ 8 % закрытых) и `snapshot_file` (выгрузка, вручную положенная в `data/import/branches/`). Сопоставление регионов — столбец `regions.okato`. Сетевых клиентов нет; кэш на клиенте 24 ч.

## Последствия
Корреляции CSI/ВСП на синтетике помечаются «демонстрационные данные». Размер сети и доля закрытых — открытые вопросы 13 (ТЗ 20.3), значения по умолчанию можно менять в данных без ADR.
