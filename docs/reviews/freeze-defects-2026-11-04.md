# Дефекты приёмки стенда: 4 ноября 2026

## Воспроизведение и исправления

1. Native mock soak на 200 клиентах после трёх полных дней падал в
   `team.plan`: SQL NULL system_code превращался в строку `"None"`.
   Nullable значение сохраняется. Если исходная система или продукт неизвестны,
   соседняя регрессия не планируется: выдумывать исходную систему нельзя.
   Число RNG draws на выборе вероятности, p_regression и путь для известной
   системы/продукта сохранены. Старые journal/checkpoints не переписываются.
2. Personal показывал ответ на дочерний SIG, которого не было в Journey
   родительского SIG. Journey читает membership той же personal-сессии и того
   же run, до 200 сообщений/200 доставок, как personal API. Чужой NULL client,
   parent hint и общий incident не доказывают принадлежность разговору.
   Добавляются реальные сохранённые факты; Trace API не изменяется.
3. `Спасибо. Как проверить статус обращения?` попадало в gratitude раньше
   общего распознавания вопроса. Вопрос не поглощается благодарностью. Только
   для anonymous personal followup с сохранённой историей и mock info_request
   есть подсказка, где появляются обновления. Новый incident/gift не создаётся;
   подсказка не утверждает текущий статус или факт устранения. Human/financial
   guards выполняются штатно. Чистая благодарность остаётся gratitude.
4. Пустое `KEY= #comment` читалось как значение из комментария. Редактор
   сохраняет пустые значения в кавычках и комментарии. Шаблон обновлён;
   legacy comment-only STT_MODEL_PATH означает штатный поиск модели.
   Рабочие .env, ключи и настройки провайдеров этим PR не редактируются.

API/DDL/events, формулы денег, пороги, ставки, HITL и численные параметры
симуляции не меняются. Cross-layer согласован пользователем в исходной задаче.

## Проверки

До исправлений пять адресных unit cases воспроизводили отказы; после исправлений
88 адресных tests прошли. Добавлен PostgreSQL personal → mock → Journey тест
для parent/child, чужой сессии и чужого run; read-only GET запрещено вызывать LLM.
Полные результаты длительного повтора и CI фиксируются в PR после выполнения.

Предыдущий live smoke SIG-004834/4835 на основном стенде подтвердил сохранение
порядка timestamps, но реальные LLM шаги ушли в mock fallback из-за quota/timeout.
Это не успешный GigaChat proof. Telegram был выключен. Personal STT API прошёл
синтетический WAV с точным текстом, без внешних STT и микрофона пользователя.

## Откат и ограничения

Откат — вернуть код предыдущего образа; миграций нет. Ранее записанная история,
включая один legacy gift timestamp, остаётся неизменной. Включение Telegram,
смена ключей/квот и operator reconciliation неизвестного API usage не выполняются.
Native soak с 200 клиентами/mock не доказывает 14 дней на 5000 клиентах/live LLM
или эмпирическую экономическую эффективность. Итоговый merge только по зелёному CI.
