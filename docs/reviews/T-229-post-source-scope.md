# T-229: адресат дорожки при входе по POST

Actual GET на собственной synthetic UI DB вернул чужую доставку для
`/api/journey/POST-000001?run_id=all`, хотя вход по SIG уже фильтровался.
Исправление разрешает адресата только по нативной связи post→signal.
Author hint не даёт права считать частную доставку увиденной клиентом.
При неизвестном или неоднозначном signal частные доставки скрыты,
публичные ответы под самим post остаются видны. Денежные записи, агент,
HITL, формат DTO и API/DDL не меняются.

Два новых unit regression сначала упали: неверный author hint и post без
связанного signal. После исправления все9 client-scope/escalation unit прошли.
Откат — revert; данных это исправление не записывает.

Полный make test был запущен до этого дополнения:1430 unit/18skip,
287 integration/2skip,43 scenarios/2skip,31 compliance,330 frontend прошли.
Post-fix подготовлен во время этого прогона, поэтому эти результаты не
выдаются за проверку неизменного финального head. Для него выполняются
отдельные адресные tests/coverage/browser и новый полный CI перед merge.
