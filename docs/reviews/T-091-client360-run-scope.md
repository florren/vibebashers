# T-091: изоляция Client360 — contract-change, human review обязателен

Статус: предложение подготовлено; до подтверждения техлидом не merge.

Основание: AGENTS.md правило 13 (строка 150) требует «ленты и карточки — baseline + текущий»; ТЗ §4.6, «Поведение», требует baseline + текущий по умолчанию для карточек. Исключения для Клиент360 нет. Текущий GET `/api/clients/{id}/360` читает все запуски неявно, а контракт не предоставляет выбора области. Поэтому исправить исторический просмотр и текущую область только реализацией невозможно.

Изменение: добавить существующий необязательный `#/components/parameters/RunId` в GET `/api/clients/{id}/360`. Параметр `ops_hours` и форма Client360 не меняются. По умолчанию `run_id=current`: baseline + текущий, при отсутствии current — только baseline. `run_id=<id>`: baseline + выбранный запуск; `run_id=all`: явно выбранная история всех запусков. Клиент/его продукты — вне запусков по схеме; сигналы, операции, инциденты, состояния и подарки ограничиваются выбранной областью. Окно операций считается в симуляционном времени, не относительно wall clock.

OpenAPI: 1.5.11 → 1.5.13 в этой ветке от f594c43. Версия 1.5.12 уже предложена T-067, PR #152: при интеграции T-091 зависит от его human review/merge либо требует согласования номера версии. Изменения T-067 (input bounds и 429) не должны быть отменены. Этот diff меняет только версию и один параметр пути clients; regenerated TS добавляет только необязательный run_id в соответствующий query type.

Совместимость: запросы без run_id сохраняют URL и DTO, но исправляют прежнюю ошибочную область all на согласованную current+baseline. Клиенты, которым нужна полная история, передают `run_id=all` явно. UI показывает область и передаёт выбранное значение; cache key включает run_id и ops_hours. Новых таблиц, миграций, событий и записей в БД нет.

Проверки: contracts_check, OpenAPI drift, regenerated types; реализация и regression checks добавляются следующим commit T-091. Ревью должно подтвердить: область baseline+selected, явный all, отсутствие отката T-067, номер версии и совместимость потребителей Client360.
