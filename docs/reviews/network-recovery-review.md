# Восстановление после временного разрыва сети

## Состав и граница review

Пакет объединяет T-003, T-031 и T-056. API, DDL, формулы, ставки, caps,
полномочия HITL и настройки провайдеров не меняются.

- [Перезапуск контейнеров](install-cached-restart.md): `bash ./install.sh --restart`
  использует существующие контейнеры и образы. Работающий PostgreSQL сохраняется;
  нет build/pull, seed, reset, изменения `.env` или запуска Tuna.
  После миграций Docker CMD выполняет `exec uvicorn`: SIGTERM получает сервер,
  чтобы штатный shutdown завершился до перезапуска контейнера.
- [Симулятор](network-sim-recovery.md): текущий автономный loop ждёт возвращения
  PostgreSQL и повторяет только доказанно незафиксированный tick. PRE проверяется
  повторно внутри транзакции под блокировкой строки. Новый run не создаётся.
  Ручные Pause/Stop отменяют восстановление. Неизвестный COMMIT или чужой прогресс
  дают безопасный отказ без перезаписи истории.
- [Очередь агента](network-agent-recovery.md): после LISTEN выполняется ограниченный
  поиск новых сигналов. Атомарный захват исключает два AgentRun. Любой существующий
  AR исключает автоматический повтор через catch-up, включая failed, HITL и unknown
  usage. Захват завершается до графа и HTTP.

Tick использует локальные генераторы и общую транзакцию PostgreSQL, без provider
HTTP. Платные попытки и внешняя доставка сохраняют прежние durable ограничения;
неизвестный результат не становится разрешением повторной отправки.

Это review границы восстановления транзакционных эффектов по AGENTS.md §5.1.
Не согласовываются новые выплаты, изменения лимитов или автоматическая обработка
старых неоднозначных операций. Merge не выполняет reset/seed, не запускает
симуляцию и не разрешает новые live-проверки LLM/Telegram.

## Подтверждённые факты и ограничения

Причина исходной остановки run #2 в 08:33 не установлена. Доступный журнал не
доказывает связь остановки локальных часов с сетью. Отдельно воспроизведён timeout
PyPI при build установщика; cached restart устраняет эту зависимость перезапуска.

При неизвестном COMMIT нужен перезапуск backend без reset и затем явное
возобновление с authoritative state. Обновлённые backend/agent загружаются только
при обновлении контейнерного образа; одного изменения host-файлов недостаточно.
Tuna имеет собственный reconnect; новый supervisor и новые внешние probes не
добавлены. Таймаут 3/8 секунд относится к recovery connection симулятора.

Адресные и native результаты приведены в дочерних review. Общие `make lint`,
`make test`, контракты, owners и CI проверяются для объединённого commit перед
merge; успех отдельного пакета не считается успехом общего gate.

До объединения: installer — 26 адресных тестов, расширенный набор 77 passed и
native Compose/PG с проверкой JSON health PASS; agent — 32 адресных, расширенный набор 39 passed,
изменённые statements 85,71%; simulator — 34 passed (17 новых и 17 соседних),
изменённые statements 96,49%. Адресные наборы входят в расширенные и не суммируются
как уникальные тесты. Проверки использовали собственные синтетические данные;
основной стенд не изменялся, внешние provider HTTP не выполнялись.

Privacy-регрессия listener использует те же `timeout=2/stop_after=20`, что native
psycopg: тестовый двойник обновлён без ослабления проверки доставки appended event.
Вместе с reconnect unit-регрессиями — 18 passed.

Native image smoke подтвердил реальный startup, оба health, Start → 3 tick →
Pause → Stop, сохранение run/time/RNG и отсутствие provider attempts. В отдельном
причинном повторе того же образа единственное изменение CMD — `exec` перед uvicorn:
PID1 стал uvicorn, `docker stop` завершился exit 0 за 1,359 с со всеми shutdown
markers; исходный shell CMD завершался exit 137 после 30 с. Это проверка сигнала
на собственных контейнерах, не утверждение о причине исходной остановки в 08:33.

## Внедрение и откат

Сначала сохранить приватный полный backup и прежний image ID, собрать и проверить
новый образ до остановки приложений. Обновить backend/personal без удаления томов
и без reset/seed. Проверить оба health endpoints и актуальный run. Автоматический
Start/Resume при rollout не выполняется.

При отказе вернуть прежний образ с сохранением БД. Историю, sim time/RNG,
операционный ledger и решения HITL вручную назад не переводить. Изменений схемы
или обязательного downgrade нет.
