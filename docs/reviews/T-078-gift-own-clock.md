# T-078: часы собственного контекста автоматического подарка

## Конкретное изменение для review

`app/agent/gifts.py::issue_automatic` берёт timestamp из `ctx.sim_time`
вместо глобального `sim_state.sim_time`. В production этот контекст обновляется
общим effect-time fence перед инструментами; historical context сохраняет
свои часы по уже утверждённой границе T-161/PR #193.

В результате `gift_offer.sent_sim`, `task.resolved_sim` и
`payload.issued.sim_time` согласованы с собственным контекстом resolution,
даже если оператор выбрал другой запуск или current pointer отсутствует.
Сумма 600 в тесте — существующие баллы фикстуры, не новое значение policy.
Выбор подарка, сумма, ready/after_resolved, HITL, экономическая формула
и пересчёт economics в этом diff не меняются. Ручной API задач не меняется.
API/DDL/events новых нет. Production migration, выплаты и external calls
не выполняются; старая история автоматически не исправляется.

## Воспроизведение

Тест использует настоящие PostgreSQL, normalizer, create_incident,
create_task и update_incident. После подготовки собственной gift-задачи
переключает current через штатный create_run и явно устанавливает часы
тестового sim_state: create_run сам меняет pointer, а не sim_time.
Случаи: тот же run, чужой run с часами −1/+1 день и отсутствие current.
До исправления: 3 failed / 1 passed, 22.22s. Нарушались времена уведомления,
задачи и issued payload; сама resolution оставалась на своих часах.
После исправления: 6 passed (4 новых + terminal gift + manual tasks),
33.44s; Ruff/formatter зелёные. Полный unit/CI — дополнительные merge gates.

## Границы результата

Это воспроизведение производящего кода, но оно не доказывает причину
конкретного старого gift notification 25 из аудита рабочего стенда.
Там timestamp раньше первой записанной resolution, real timestamps равны.
Его не корректируем и не исключаем из аудита.

Ручная выдача исторической задачи в `api/tasks.py` тоже читает глобальные
часы; для неё нужен отдельный выбор поведения при отсутствии своего active
clock. Этот PR не вводит запрет исторических решений и не выдумывает
mapping чужого времени. Поэтому вся история не объявляется исправленной.
