# T-267 — поиск сигналов и непрерывный ввод HITL

30.10.2026, GitHub #95, ADR-0015, OpenAPI 1.5.5, миграция 0009.

## Проверенная причина

SIG-088489 сохранён в SR-0009 со статусом deferred. HD-001351 не решён: decision/decided_by = null. INC-000826 имеет тип tariff_terms, repeat_negative — причина эскалации ESC-000085. Граф AR-001549 создал non-blocking эскалацию и дошёл до followup_monitor, без wait_human. Старый поиск искал только текст, Signals ограничивался текущим запуском и первой страницей; HITL показывал последние 50 без поиска/пагинации. Поэтому запись переставала быть видимой, хотя не удалялась.

## Изменение

Все статусы, все запуски по умолчанию в операторских списках; текущий запуск выбирается явно. Поиск использует общий реестр SIG/INC/HD/AR/ESC/TSK/NTF/FUP/CL/POST/TR/AS/EMP/CSI/VSP/RULE/SR/LED/ошибок, UUID и токенов. Результаты ограничены выбранным запуском, поиск конкретного SIG не расширяется через общего клиента. Связанные коды видны даже без отдельного HD; максимум 100 ссылок, усечение обозначено. Списки и история журнала пагинируются.

Карточка показывает SIG→INC/HD/ESC/SR. Выбранный HD и общий черновик сохраняются при обновлении очереди. Только открытый HD с точным wait_human checkpoint возобновляет граф; non-blocking эскалация обрабатывается без replay. Информация оператора доступна в любом состоянии HD, добавляется в историю идемпотентно, не заменяет прежнее решение и не повторяет деньги/граф. Это сохранение информации, не новое автоматическое исполнение старого предложения.
