# T-265 / E24 — проверка двух контуров прототипа

29.10.2026. ADR-0014; все клиенты, обращения, сделки и доказательства в этом отчёте синтетические. Рабочие контрольные данные и бизнес/юридическое основание реального штрафа не предоставлены. Рабочий контур показывает null, а не демо-суммы. Демо-калибровка не измеряет качество реальной NLP.

## Воспроизводимость

`backend/.venv/bin/python scripts/gen_churn_demo.py` повторно создаёт идентичные 2 000 контрольных строк и артефакт. Разные клиенты в train/validation (1 000 / 1 000), горизонт 7 календарных сим-дней. На отложенной синтетике Brier 0.2034394 → 0.168315, ECE 0.023. Хеши и исходные данные — data/economics/. Совпадение хеша означает целостность, а не бизнес-согласование.

Браузер: собранный frontend, FastAPI + PostgreSQL во временной БД, lite baseline на 200 синтетических клиентов, mock QR-сценарий и отдельный синтетический misselling-кейс того же клиента. Последовательные screenshot/assertion проверки ru/en × light/dark, ширина 390 px, запись через настоящую форму. Нет перехвата API или подмены его ответов. report.json содержит ошибки JS и горизонтальный overflow.

`CX_BASE_URL=http://localhost:8000 CHROME_EXECUTABLE=/path/to/chrome CX_SCREENSHOT_DIR=/tmp/finance-proof node docs/benchmarks/finance-calibration-2026-10-29/capture.mjs` запускается на специально подготовленном демо-стенде с решённым misselling-кейсом и алертом. Скрипт добавляет демо-декларацию; не запускать против рабочего контура. Время доказательства в скрипте задано для этой синтетической фикстуры.

## Проверенные свойства

- Реальный mock-граф сохранил model=mock:mock-rules-v1, prompt=v1.1, score_pipeline=agent-score-v1, время прогноза и step_id. Два кейса одного клиента дают одну риск-оценку 194.85 ₽ и возвраты 450 + 10 ₽. Чистая риск-оценка −265.15 ₽.
- go без доказательства дал 0 ₽ штрафа. Запись через форму допустила одну демо-сделку на условные 50 000 ₽. Совместная модельная оценка 49 734.85 ₽. Это не доход и не реальное регуляторное основание.
- Рабочие риск, штраф и совместный итог остались null. Известная часть показана отдельно.
- API-тесты проверили идемпотентный повтор, конфликт ключа, новую версию одной сделки без удвоения, отзыв, позднее вмешательство, отсутствие политики, чужой алерт/запуск, лишнее поле суммы, время без TZ и отсутствие новых денежных проводок. Неизвестные/устаревшие возвраты не дают полного net.
- Живой QR-сценарий через GigaChat: normalize и instant_decide выполнены GigaChat-3-Ultra:32.9.16.9, status=ok (live-smoke.json). TLS включён, кассеты не записывались; использованы только синтетические данные. Это интеграционный smoke, не валидация калибровки на реальных клиентах.
- Покрытие новых calibration.py/evidence.py unit/integration тестами: 93 % суммарно (calibration.py 93 %, evidence.py 92 %).
