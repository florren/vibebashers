# #140: проверка команды до конечного ответа

Контроль после установки #139 подтвердил завершение SIG-001035 на паузе и завершение
исходного AR153/SIG-000877. Однако SIG1035 получил старый summary INC-000241
«Спор о тарифах/комиссии,1290 ₽». На инциденте был demo release_note, но ещё не было
verification_report: обычная verify по уже устранённому fault обошла проверку команды.
APP-CRASH-PAY был выбран для ошибки503 открытия вклада из-за слишком общего совпадения
по слову «приложение» и гипотезы модели.

Теперь агент ждёт закрытия активного плана emulated-team через verify/close команды.
Это ожидание не вызывает reopen/escalation и не дублирует followup. После закрытия
оригинальный граф продолжается штатно. Для уже закрытой исторической цепочки с demo
release_note используется клиентский формат после обычной проверки verified;
внутренний устаревший summary не попадает в ответ. Неподтверждённый close по-прежнему
запрещён. Подарки, согласования и выдача денег не меняются.

APP-CRASH-PAY требует описания падения/зависания в платёжном сценарии либо явного кода.
Ошибка503 открытия вклада не наследует этот код ни из чужой операции, ни от модели.
Другие соответствия error_code и правила инцидентов сохраняются.
