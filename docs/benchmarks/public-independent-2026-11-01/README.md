# Независимый публичный контур и восстановление после эскалации

Задача: #144. Контракт API 1.5.11 (аддитивный): отдельный POST восстановления,
`can_recover` в состоянии Journey. Финансовые правила и решения HITL не изменены;
внутренний оператор передаёт локальное время решения через Request.state.

Публичный чат создаёт собственный paused live-run без изменения sim_state.current_run_id.
Сохранённые исходы назначаются новым инцидентам под блокировкой строки запуска,
курсором on_time → late → no_work → failed. Связанные сигналы используют
один инцидент; повтор не расходует следующий исход. Восстановление не выбирается
для нового публичного кейса: это отдельное продолжение no_work/failed после
первого отрицательного ответа. Оно запускается через 30 реальных секунд либо
раньше по повторному сообщению, идемпотентно для обоих триггеров. У публичного
исполнения отдельные asyncio worker и lock; длительная работа Journey его не блокирует.
Целевой бюджет до конечного ответа — не более 1–3 минут, без искусственной задержки
успешных исходов. HTTP-тест готового образа до уточнения сценариев занял 30,07 с. Техническое выключение агента
останавливает и публичную обработку; настройки Journey ей не управляют.

Восстановление — явное действие для ручного failed/no_work инцидента в escalated.
Новая попытка записывается append-only с outcome=recovered; загрузка берёт последний
сохранённый план. Выполняются решение о фиксе, релиз, проверка и закрытие того же
инцидента. Сохранённый профиль Journey и прежние уведомления не переписываются.

Проверка GigaChat на копии стенда: SIG-000803 → тот же INC-000153 → closed,
исходный AR-20 → completed. Сохранён один demo_unresolved, добавлен один resolved
с извинением за задержку. Отдельный синтетический публичный сигнал завершился при
выключенном профиле Journey. Все 15 LLM-вызовов live; 15,95 с на оба кейса без
учёта прогрева. Часы и текущий запуск банка не изменились. Подробности: live-copy.json.
Первый холодный запуск ушёл в mock по таймаутам OAuth; после штатного prepare
проверка повторена на свежей копии и прошла целиком на GigaChat.

Chromium: кнопка восстановления отправляет один запрос только выбранному инциденту,
не сохраняет профиль и не запускает сценарий. Проверены light/dark × ru/en;
скриншоты — ../../screenshots/public-independent/.

Обновление старой публичной сессии с историей из общего запуска: история остаётся
доступной, для нового отдельного контура требуется «Новый чат» (409 предотвращает
неявный перенос разговора между запусками). Открытые старые инциденты не переносятся.

Откат: предыдущий Docker image и резервная копия БД до установки. Миграций схемы нет;
предыдущие действия и сигналы не удаляются. Новый публичный запуск остаётся в истории.

## Уточнение демонстратора: восстановление только вторым сценарием

Для новых публичных инцидентов остаются четыре первичных исхода. После no_work
или failed сначала сохраняется отрицательный ответ. Через 30 реальных секунд
запускается отдельная попытка recovered в том же инциденте; повторное сообщение
по общей проблеме запускает её раньше. Конкурирующие триггеры не дублируют решение,
уведомления и исходный граф. Назначение начального исхода и курсор сохраняются.

22 PostgreSQL-регрессии обновлённого публичного и ручного контура прошли: четыре
первичных исхода, независимый lock, обе ветви восстановления для no_work/failed,
тот же инцидент, завершённый исходный граф, неизменные часы банка. Проверки таймера
детерминированы через переданное реальное время, без ожидания 30 секунд в тестах.
Публичное исполнение вынесено в отдельный worker; фоновые задачи других запусков
не блокируют изолированное демо Journey.


Финальный HTTP-прогон собранного образа, два отдельных процесса и копия БД:
no_work → автоматическое восстановление — 54,08 с до конечного ответа (первый
отрицательный — 13,04 с, новая попытка через 30,31 с); failed → повторное сообщение
→ восстановление — 50,07 с (первый отрицательный — 25,03 с, повтор ускорил старт
до 14,71 с вместо 30 с). В обоих случаях один инцидент, одна дополнительная
попытка, исходный граф completed, курсор не сдвинулся, часы/указатель банка не
изменились. Подробности: http-recovery.json. Обе цепочки завершились быстрее 180 с.

9 публичных регрессий повторены с фиксированным реальным временем таймера — все
прошли. Полный локальный make test первоначальной версии завершился: 697 unit,
206 integration, 42 scenarios прошли; финальный CI текущего head обязателен до merge.
