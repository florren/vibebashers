Эпик [#127](https://github.com/florren/vibebashers/issues/127), задачи

## Диагноз SIG-105875

Проверено на локальном стенде до изменений: SR-0011 — `scenario/paused`,
профиль — `mode=simulation`, `auto_advance=false`, `emulate_humans=true`.
Агент 2127 завершил первичную обработку как `deferred`; сигнал связан с
INC-001394 (`escalated`), followup 382 — `awaiting_team`, согласование
`repeat_negative` 1900 не решено. Предыдущее согласование `ultra_vip` 1899 принято.
Worker проверял одновременно `configuration.status=running` и `SimClock.running`,
поэтому на паузе не выполнялись ни команды, ни сотрудники, ни итоговый ответ.

## Исправление

Существующий `auto_advance` в общем профиле включает ускоренную обработку ручных
входов `origin=jury`. Время хранится отдельно для каждого инцидента в
`settings_snapshot.demo_execution.manual_times`; часы банка и фоновые генераторы
не меняются. Один ожидающий сигнал не блокирует независимые инциденты.
Настройка сохраняется и действует после перезапуска. Новые профили ускорены по
умолчанию; существующее явное `false` меняется переключателем и кнопкой сохранения.
Незавершённая работа остаётся открытой с уведомлением об эскалации.

Каждый ручной ввод создаёт новый сигнал через нормализатор. История клиента уже
собиралась по `client_id`; исправлен подбор инцидента после классификации текущего
сообщения. Разные коды ошибки одного клиента не объединяются по типу `tech_fault`.
При отсутствии кода требуется совпадение клиента, типа, продукта, системы и слов
описания. Изоляция запусков и окно поиска связанных инцидентов сохраняются.

## Ограничения

Реальное время вызова LLM не ускоряется. Выключенная эмуляция сотрудников
оставляет согласования человеку. Старое обращение не считается исправленным
одной правкой кода: для SIG-105875 требуется включить ускоренный профиль после
обновления локального стенда и дождаться подтверждённого итога.
Проверка с GigaChat требует отдельного разрешения на внешнюю передачу синтетического
текста; автоматическая проверка разрешений отклонила такой запуск.
