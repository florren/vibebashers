# Благодарность после истечения OAuth — #146

Основной кейс SIG-000809 / AR-36 завершился на GigaChat в 10:10 UTC.
Благодарность SIG-000810 / AR-46 пришла в 10:12 UTC: токены, полученные в
09:41:50–51 UTC на 1799 секунд, уже истекли. Нормализация исчерпала 4/3/3 секунды
резервных моделей; classify и decide также упёрлись в OAuth/transport timeout.
Граф агента был исполнен, результат честно отмечен fallback_mock. Клиенту
отправлено название класса «Благодарность» вместо нормального ответа.

Изменение: prepare запускает отдельный OAuth worker. Каждые 30 секунд он проверяет
ключи и обновляет токены за три минуты до истечения, с отдельным бюджетом 12 секунд
на ключ. При подготовке холодного OAuth/TLS используется её бюджет, а не
двухсекундный connect-лимит генерации. Пока фон работает, генерация использует
ещё действующий кэш, без ожидания блокировки OAuth. Сетевые ошибки подготовки не
обнуляют рабочий кэш, 429/auth соблюдаются; ошибки логируются. Настоящая
недоступность провайдера по-прежнему допускает честный fallback.

Задача останавливается при shutdown и смене цепочки; уже выполняющиеся запросы
старой цепочки продолжают использовать её HTTP-клиент. Новая live-цепочка
подготавливается при применении настроек. В явном mock/replay авторизация не
запускается. Для резервной благодарности задан вежливый ru/en ответ, без создания
инцидента и финансовых обещаний. Промпты, API, политика денег/HITL не меняются.

Проверки: 30 unit-регрессий OAuth/cold-start/lifecycle, 6 PostgreSQL-регрессий графа
и редактора настроек прошли; первоначальный полный unit-прогон 708 passed,
18 skipped. make lint: ruff/format/mypy/OpenAPI drift 191/191 прошёл.
Полный make test и CI текущего head обязательны до merge.

Живая проверка: отдельный процесс в штатной Docker-сети с копией БД. Только в
тестовой памяти срок кэшированных токенов сдвинут до +120 секунд, чтобы проверить
реальный фоновый worker без ожидания получаса. Worker сам обновил оба токена;
после этого синтетическая благодарность с parent SIG-000809 прошла три live-вызова
GigaChat за 6,28 секунды, OAuth внутри графа — 0, новый инцидент — 0. Ответ:
«Спасибо за тёплые слова! Рады, что помогли разобраться с условиями вклада и
приложением. Если появятся вопросы — мы на связи.» Часы сохранены, исторический
fallback AR-46 не переписан. Протокол — live.json.

Два хостовых предварительных прогона не прошли по сетевым таймаутам; успешный
прогон выполнен в штатном контейнерном окружении. Это не гарантия отсутствия
fallback при внешних сетевых сбоях.

Установка: защищённый snapshot БД и предыдущий image до обновления backend;
миграций схемы нет. Откат — предыдущий image. История ответов не переписывается.
