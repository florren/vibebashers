## 1. Что должно работать 4 ноября («первая реализация»)

Один запуск `./install.sh --profile lite` на ноутбуке демонстратора поднимает стенд, на котором проходят без ручных подпорок:

1. **Ядро**: симулятор генерирует сигналы → агент классифицирует (`sentiment`, `problem_summary`) → `route_to_department` создаёт инцидент/тикет → HITL-очередь и эскалации → карта с зонами → лента и карточка инцидента → экран «Под капотом» показывает живую трассировку и цепочку решений.
2. **Сценарий 8** (публичный отзыв о комиссии за QR → правило → `refund_fee` в Mock-АБС → публичный ответ на `/feed`).
3. **Сценарий 9 из файла** (транскрипт отделения → счётчик мисселлинга → алерт на `/manager`). Живой микрофон — после 4.11.
4. **Сценарий 10** (файл TXT → отчёт о «красных фразах» с рекомендациями → алерт immediate).
5. **Подстраховка**: `replay`-кассеты для сценариев 8–10, автоматический failover live → replay → mock, бейдж режима.

Период 5–8 ноября — репетиции, запись кассет на реальном GigaChat, микрофон как стретч, демо-скрипт. 9 ноября — демо.

## 3. Пакеты по дням

Пакет = одна сессия агента (3–6 часов) по нескольким карточкам с указанными урезаниями. Запуск: `python scripts/cx.py start Bxx` — скрипт сам создаёт worktree, собирает промпт из этой таблицы (карточки + урезания) и запускает агента; `cx next --seat S1|S2|S3` подсказывает пакет на сегодня (`docs/WORKFLOW.md`). Проверки перед PR — `cx check`, PR — `cx pr`.

## 6. Рычаги ускорения, если отстаём

1. **Снять пятичасовое окно**: Pro 100 на один месяц для места S1 или докупка кредитов на 28.10–3.11 — пиковые дни агента и контуров.
2. **Переложить на S3** всё, что проверяется без базы: парсеры, промпты, правила, фикстуры, e2e-спеки, документацию. Проверить расход кредитов после B21 и решить, сколько пакетов S3 вытянет.
3. **Не плодить ветки**: один пакет — одна ветка; внутри пакета агент коммитит часто, но PR один. Это втрое меньше накладных расходов на контекст и проверки, чем по карточкам.
4. **Кассеты раньше, чем кажется нужным**: как только сценарий прошёл на live один раз — записать кассету; дальше вся разработка и тесты идут на ней, а квоты LLM не тратятся на повторные прогоны.
5. **Не трогать контракты** в спринте без крайней нужды: каждое изменение `contracts/` — это пересборка типов у трёх мест и день потерь на интеграции.
