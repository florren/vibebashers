## Что сделать
1. Вкладки по контракту; таймлайн статусов с акторами; артефакты в Markdown с отметкой «в срок/опоздание»; логи систем с подсветкой error_code; коммуникации по каналам с реакциями двойника (тон, удовлетворённость); экономика с formula_ru и развёрткой; регрессии, вызванные фиксом.
2. Действия: перенаправить, ответить клиенту, запросить данные, эскалировать, закрыть, дубликат, приоритет — по available_actions; подтверждения.
3. Ссылка «Под капотом» на запуск агента.
