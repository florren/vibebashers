## Что сделать
1. Степпер из 9 шагов с сохранением на каждом шаге и возможностью вернуться; валидация форм (zod).
2. Шаг LLM: список профилей, добавление ключей, кнопка «Проверить подключение» с результатом; шаг каналов: Mailpit, токен бота и проверка; шаг политик: пороги, матрица SLA 3×3 с днями отчётов, справочник подарков; шаг экономики: доли, коэффициенты удержания, таблица ставок; шаг языка/темы; шаг генерации с прогресс-баром, логом и матрицей покрытия; шаг сценариев.
3. Экран «Настройки» — те же формы во вкладках + экспорт/импорт JSON + вкладка «Психотипы» (параметры и доли, валидация суммы = 1).
4. Пустые состояния и ошибки на русском/английском.

## Критерии приёмки
