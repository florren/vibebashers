## Цель
Публичная страница в стиле ленты отзовика/Telegram-канала, где зритель видит пост → цепочку агента → проводку возврата → ответ под постом (ТЗ 12.2 экран 8, 12.6).

## Что сделать
1. features/feed: лента постов (аватар-инициалы, ник, время, текст, реакции), форма «Написать отзыв» (ник, текст, чекбокс «упомянуть карту **** NNNN»), ветка ответов с бейджем «Ответ банка · ИИ-агент CX» и временем реакции; статусы постов.
2. Виджет «АБС (эмуляция)»: клиент, счёт, баланс, последние проводки с анимированной подсветкой fee → refund по WebSocket abs.
3. Панель Log (общий компонент T-201) внизу, развёрнута в режиме показа; бизнес-строка эффекта из ExternalPostDetail.effect_line_ru.
4. Нейтральный бренд площадки «Отзывы о банках», без реальных логотипов; обе темы, i18n; работает без роли на отдельном устройстве.
5. Playwright-смоук: публикация поста → появление ответа ≤ 15 с на кассете.

## Критерии приёмки
- [ ] Скриншоты обеих тем в PR; нет внешних URL.
- [ ] После публикации поста первое событие на панели Log ≤ 2 с (на кассете).
- [ ] Виджет АБС показывает изменение баланса без перезагрузки.
- [ ] `make lint && make test` зелёные; Definition of Done из AGENTS.md §8 выполнен.
