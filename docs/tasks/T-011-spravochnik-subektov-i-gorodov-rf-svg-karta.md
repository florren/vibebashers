## Что сделать
1. data/regions.csv (код, названия ru/en, округ, население, центроид, svg_path_id), data/cities.csv (≥ 300, центры субъектов отмечены).
2. public/map/russia.svg с id контуров = svg_path_id; оптимизировать (svgo) до ≤ 400 КБ.
3. data/README.md: источники данных и лицензии (только открытые — Росстат/OSM/Natural Earth или аналог), дата выгрузки.
4. Загрузчик scripts/seed/refs_geo.py (идемпотентный).

## Критерии приёмки
- [ ] 89 регионов, 8 округов, ≥ 300 городов загружаются без ошибок; у каждого региона есть контур.
- [ ] Сумма населения регионов согласуется с распределением клиентов (используется в T-016).
- [ ] Лицензии указаны.
- [ ] `make lint && make test` зелёные; Definition of Done из AGENTS.md §8 выполнен.

## Как проверить
```bash
python scripts/seed/refs_geo.py --check
```

## Отчёт субагента
Ветка main, коммит B21. `data/federal_districts.csv` (8), `data/regions.csv` (89 субъектов, код КЛАДР/ФИАС, население, условный центроид = адм. центр, `svg_path_id`=RU-NN), `data/cities.csv` (1 121 город из hflabs/city CC BY-SA 4.0, атрибуция в data/README.md, добавлены центры 4 новых субъектов). Загрузка — `scripts/seed/refs.py::seed_geo` (upsert, COPY с фиксированными id). Отклонение: SVG-контуры регионов не включены — центроиды временно равны координатам адм. центров (для Московской и Ленинградской областей — условные точки). Время: ~25 мин.
