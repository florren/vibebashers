## Цель
Дублирование compliance.alert сообщением в Telegram с цитатами и кнопками решений (ТЗ 22.6, 11.3).

## Разделы ТЗ (docs/TZ.md)
§11.3, §22.6

- Блокирует: —

## Что сделать
1. tgbot: обработчик алертов (backend → бот через internal API или очередь в БД), сообщение «Стол 3 · Петров П. П. · 3 нарушения» с цитатами, inline-кнопки «Иду»/«Ложное»/«Открыть инцидент» → POST /alerts/{id}/ack.
2. Настройка manager_chat_id на отделение; команда /manager в боте для привязки чата (роль руководителя — переключатель).

## Критерии приёмки
- [ ] Алерт приходит в чат ≤ 3 с; нажатие кнопки меняет решение в HITL.
- [ ] Без токена бота функция выключена без ошибок.
- [ ] `make lint && make test` зелёные; Definition of Done из AGENTS.md §8 выполнен.

## Как проверить

pytest tgbot/tests/test_compliance_alert.py
