## Отчёт субагента
- `frontend/e2e/smoke.spec.ts` + `frontend/playwright.config.ts` (`E2E_BASE_URL`, по умолчанию :8000), `npm run e2e`, `make e2e`. Проверки: 5 экранов (`/?tab=signals|incidents|hitl|deferred`, `/engine`) открываются без ошибок консоли, без внешних запросов и без сырых ключей i18n; путь лента → drawer → карточка инцидента → «Под капотом»; переключение и сохранение тёмной темы; мобильная ширина без горизонтального скролла.
- Отклонения: визуальная регрессия по эталонным скриншотам не включена (эталоны меняются с каждым пакетом); скриншоты делаются только при падении. В CI e2e не запускается (нужен стенд) — цель `make e2e` для ручного прогона.
