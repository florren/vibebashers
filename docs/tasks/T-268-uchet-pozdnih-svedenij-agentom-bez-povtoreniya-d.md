## Что сделать
1. Надёжная очередь дополнений, отдельный операторский разбор LLM и прослеживаемый agent_run, применение только нового плана.
2. Новые сведения в контексте следующих решений и возобновлений; не повторять исходный act, деньги, уведомления или формальный ответ.
3. Атомарные эффекты, идемпотентность, конкурентные повторы, восстановление и видимый статус применения/ошибки; закрытые кейсы только на ручной повторный разбор.

## Критерии приёмки
- [x] Агент учитывает дополнение в дальнейшем плане связанного инцидента и следующих контекстах.
- [x] Повтор/сбой не дублирует эффекты; деньги и прежние решения не меняются.
- [x] Статус и прогон разбора видны в HITL; есть regression и проверка стенда.
- [x] `make lint && make test` зелёные; Definition of Done из AGENTS.md §8 выполнен.
