## Что сделать
1. Адаптеры центральной карточки: сигнал, инцидент, клиент (360-вид и «момент»), пост, транскрипт и сессия, эскалация, задача и решение человека, уведомление, проводка (сумма, ссылка на исходную комиссию), запуск агента, сотрудник и отделение, токен трекинга.
2. Рендеры событий по `trace_event_kind`: иконка, форма, цвет роли, формат ключевых фактов, сумма в ₽ для денег, бейджи `live|replay|mock`, политика/правило, маскирование (`**** 4512`, `+7 900 ***-**-12`).
3. Единый реестр `kind → компонент` с исчерпывающей проверкой (`switch` с ветвью `never`, правило типизации) — новое значение перечисления ломает сборку, пока не обработано.
4. Тесты: снапшоты по типам, проверка масок, проверка исчерпывающего реестра.
