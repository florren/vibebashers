## Что сделать
1. ≈ 300 жалоб на вежливость с вариативностью текстов (грубость, равнодушие, игнорирование очереди), привязанных к ВСП, сотрудникам и направлениям; нет ПДн.
2. `csi_visits_agg`: визиты по ВСП × день × корзина ожидания × корзина перенаправлений; вероятность жалобы растёт с ожиданием и перенаправлениями (параметры в `data/csi_params.yaml`, сид `app/sim/rng.py`), стаж сотрудников с жалобами в среднем ниже.
3. Образцы XLSX и JSON для T-246; тест воспроизводимости; метка «демонстрационные данные» в метаданных набора.

## Критерии приёмки
- [ ] Корреляция Спирмена «ожидание × вероятность жалобы» > 0,5 и «перенаправления × вероятность» > 0,3 на корпусе (тест).
- [ ] Данные детерминированы по сиду; `test_no_pii` зелёный.
- [ ] `make lint && make test` зелёные; Definition of Done из AGENTS.md §8 выполнен.
