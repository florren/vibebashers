Главный интерфейс поиска по следу (ТЗ 28.5): объект в центре, что было до него слева, что стало после справа — до итогового решения, с визуально явным разделением.

## Что сделать
1. Страница `pages/trace/` и маршруты `/trace` (поиск) и `/trace/:kind/:ref`; шапка с поиском, хлебными крошками перехода по следу (кнопка «назад») и сводкой «до: N · объект · после: M · итог».
2. Режим «Колонки» (≥ 1280 px): три зоны с подписями «ДО / ОБЪЕКТ / ПОСЛЕ», вертикальными разделителями, иконками направления и токенами `--trace-before/subject/after`; центральная карточка объекта; закреплённый узел «Итоговое решение»; ожидаемые шаги пунктиром с часами; свёрнутые веера «+118 сигналов» с раскрытием.
3. Режим «Дорожки»: горизонтальная шкала времени, строки — клиент, агент, человек, команда, система, зоны — полосами; переключатель режимов хранится в URL.
4. Фильтры актор / слой / значимость («ключевые» по умолчанию); панель события справа (поля, вызовы инструментов в масках, бейдж источника, ссылки «Под капотом» и «Путь»); «Центрировать на нём» с историей; клавиши `[` и `]`.
5. Узкие экраны: зоны становятся вкладками «ДО | ОБЪЕКТ | ПОСЛЕ»; копирование ссылки и экспорт JSON/Markdown; все состояния (загрузка, пусто, неоднозначно, усечено) тёплыми формулировками, i18n.
6. vitest на раскладку и фильтры; Playwright-скриншоты обеих тем.

## Критерии приёмки
- [ ] Для сигнала и инцидента сценариев 1, 8, 11 видны «до», объект, «после» и итог; разделение зон понятно без опоры на цвет (подписи и разделители).
- [ ] Переход по любому объекту переcентрирует след, кнопка «назад» возвращает; ссылка воспроизводит состояние.
- [ ] p95 отрисовки следа до 200 событий ≤ 1 с; режимы «Колонки» и «Дорожки» работают.
- [ ] `make lint && make test` зелёные; Definition of Done из AGENTS.md §8 выполнен.
