# Библиотека сигналов T-019

`catalog.yaml` — исходная грамматика: 10 банковских типов, четыре продукта,
12 существующих каналов, четыре русских и два английских смысловых варианта
на тип. `app.sim.signal_corpus.SignalCorpus` разворачивает её в 2880 уникальных
полных шаблонов: 1920 ru и 960 en. Это **60 исходных смысловых вариантов**, а не
2880 независимо написанных сюжетов. У каждой ячейки тип × продукт × канал есть
четыре русских и два английских текста. Совпадающие развёрнутые тексты не
допускаются тестом; материализованной генерируемой копии нет.

`TextGen.generate(..., channel=..., language=None)` выбирает английский с
вероятностью 0.05. Явный `language=ru|en` нужен для проверки корпуса. Выбор стиля
сохраняет существующие веса/психотипы; стилизация применяется только к речи
клиента. Заголовки писем, реплики оператора и формат каналов не искажаются.
В gold возвращаются истинные тип, продукт, стиль, канал, язык и стабильный
`template_id`; они не являются результатом классификации модели. Seed хранит их
в `signals.meta.generator_hint`, отдельно от строгого `classification` DTO;
`signals.lang` совпадает с фактическим языком. Read API не публикует этот gold.

В сиде сначала сохраняется полная матрица покрытия, затем 3% строк обычных
lite/demo-профилей занимают сообщения из отдельного небанковского noise pool.
У шума status=noise, classification=null, истинные signal_type/product отсутствуют, инцидент не
создаётся. Если задано меньше строк, чем нужна матрица, покрытие имеет приоритет:
шум не вытесняет обязательные комбинации. История не меняется при повторном seed.
Runtime использует формат выбранного канала; глобальная интенсивность фоновых
сигналов и её существующий noise sampler этим пакетом не перенастраиваются.

Для совместимости вызов без `channel` продолжает использовать
`data/corpus/signal_templates.yaml`. Это сохраняет существующие диагностические
наборы и исторические входы replay. Golden corpus T-021 не генерируется заново
этим изменением; ответы реальных моделей и их hash не переписываются.

Проверка сложности использует неизменённый `app.llm.mock.analyze` только с
текстом, без gold. Текущая измеренная accuracy_type на всех 960 сложных ru
вариантах — 15%; это не доказательство качества какой-либо живой LLM.
Источники синтетические: брендов банков, личных контактов и ссылок в грамматике нет.

Активные шаблоны поддерживают суммы, относительные даты (`days`), продукт, промо
и город. Corpus tests проверяют все placeholders, отсутствие контактов/URL/длинных
card-like чисел и нейтральные bank references/аббревиатуры. Корпусная разметка
проверяется отдельно от словаря полей classification.
