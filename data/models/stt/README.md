# Модели распознавания речи (Vosk)

Каталог для моделей Vosk; сами модели в git не хранятся (`.gitignore`). Скачать малую русскую модель (≈45 МБ, ~90 МБ распакованная):

```bash
make stt-model          # → data/models/stt/vosk-model-small-ru-0.22
```

Путь переопределяется `STT_MODEL_PATH` в `.env` (мастер настройки, шаг «Каналы»). В Docker каталог `data/` смонтирован в `/data`, модель подхватывается без пересборки образа.
